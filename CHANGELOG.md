# Changelog

Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/). Записи — по дням работы,
внутри — ссылки на PR. Новые изменения добавляются в «Не выпущено», при выкладке на VPS
раздел получает дату и версию.

## [Не выпущено]

### Добавлено

- **Попапы «Отправить проект» (он же «Заказать») и «Записаться в шоурум»**: открываются любой
  ссылкой на `#send-project` / `#showroom` (шапка, CTA, карточки проектов, «Записаться в шоурум»),
  на мобильном — на весь экран. Закрытие — крестик, клик по фону, Esc. Отправка заявок — на этапе 2.
- **Лайтбокс галереи**: открывается по клику на фото или видео, стрелки как в слайдере проектов,
  клавиши ← →, свайп, лента превью, счётчик.
- **«Весь отзыв»**: текст отзыва обрезается до 5 строк, «Весь отзыв +» появляется, только если он
  длиннее, и открывает попап (на мобильном — снизу).
- **Дизайн баннера cookie** (только Figma, вёрстка — следующим шагом): баннер «Принять / Отклонить /
  Настроить +», панель настроек по категориям (основные, аналитические, рекламные), desktop и mobile.
  В UI-kit — доска «13 · Cookie»: Toggle, Cookie Category, Icon/Minus 15.
- Дизайн всего перечисленного — в Figma: доска UI-kit «12 · Попапы и лайтбокс» (Icon Button / Close,
  Lightbox Thumb) и секция «Попапы и лайтбокс — к вёрстке».

### Изменено

- **Hover кнопок**: все кнопки (CTA, «Смотреть кейс», «Заказать», «Все проекты») при наведении
  заливаются акцентным `accent-red` с белым текстом — раньше цвет почти не менялся, и переход
  выглядел как мерцание. Сначала в UI-kit: варианты `State=Hover` у Button / CTA, Button / Card
  и у иконок с квадратом.
- **Кнопки со стрелкой** (CTA, «Заказать проект», «Все проекты», шапка): при наведении стрелка
  поворачивается на 45° и встаёт ровно (→), квадрат не меняет размер. Квадрат со стрелкой теперь
  inline-SVG (`ArrowSquare`): затемнение без CSS filter — кнопки больше не подёргиваются при наведении.
- Стрелки слайдера вынесены в общий компонент `SliderArrows` (слайдер проектов и лайтбокс).
- Review в Figma: цитата ограничена 5 строками; в макете проекта — полный текст отзыва.

### Процесс

- **CLAUDE.md**: правки сначала копятся локально; push, PR и публикация — только по команде
  пользователя, одним PR на накопленный пакет.

### Изменено (шапка и слайдер)

- **Шапка** ниже по макету: desktop 75px (py 12), mobile 56px (py 12) — логотип и бургер
  на мобильном увеличены до 32px (сначала в Figma, Header / Mobile 16:97).
- **«Все проекты»**: стрелка прижата к правому верхнему углу кнопки на любой ширине — на мобильном
  теперь как на десктопе (в Figma — constraint Right у иконки в Button / Card, Sand).
- **Стрелки слайдера проектов**: стрелка красная, когда в её сторону можно листать, и серая,
  когда нельзя; кружок перепрыгивает на нажатую стрелку, а в конце ленты — на ту, что осталась
  активной. В Figma цвета стрелок привязаны к переменным (серая — `color_bg-stone-light`).
- Спека `check:layout` сдвинута под новую высоту шапки, добавлены логотип и бургер на 360.

### Изменено

- **Страница проекта** — правки после просмотра:
  - шапка на десктопе сворачивается в мини-шапку, только когда до верха экрана доходит галерея
    (intro и план уже прокручены), а не сразу при начале скролла;
  - липкий aside галереи держится в 40px от низа экрана — «Все проекты» не упирается в край;
  - видео в галерее: при наведении линии рамки дотягиваются до углов и замыкаются;
  - карточка проекта на мобильном: срез угла уменьшен до 32×20 и больше не обрезает «Заказать»
    (сначала исправлен в UI-kit Figma, компонент Project Card 14:119).
- **PLAN.md, этап 5**: на старте без staging — `main` деплоится сразу на прод (`pg_dump` перед
  миграциями, все проверки CI обязательны); ориентир по мощности VPS; HTTPS через Caddy +
  Let's Encrypt с запасным вариантом DV-сертификата; витрина с Pages переедет на прод VPS.
- **CLAUDE.md, процесс**: после merge агент предлагает удалить ненужные ветки (слитые PR без новых
  коммитов) и удаляет их через git только с согласия пользователя.

## 2026-09-23 — Этап 0 и начало этапа 1

### Добавлено

- **Каркас проекта**: Next.js 16 + Payload CMS 3 + PostgreSQL 16, TypeScript strict, Tailwind CSS 4,
  ESLint/Prettier, Docker Compose для разработки, Dockerfile для продакшена, CI (lint, typecheck,
  format, build), `CLAUDE.md`.
- **Дизайн-токены из Figma** (`npm run tokens`): цвета, радиусы, отступы и 38 текстовых стилей
  Desktop/Mobile; размеры между 1440 и 360 интерполируются через `clamp()`. Шрифт Manrope хранится
  локально. (#2)
- **GitHub MCP** для Claude Code (`.mcp.json`, токен из `GITHUB_PAT`). (#1)
- **UI-kit** (`src/components/ui`): 30 иконок из Figma, кнопки CTA и карточки, 6 типов ссылок,
  поля формы, загрузка файла, согласие, Info Chip, Feature Item, Text Block, Designer Line,
  Review. Витрина `/ui-kit` (только dev). (#3)
- **Страница проекта** `/projects/[slug]` на статических данных (`src/data`) (#4–#8):
  - шапка: на десктопе при скролле превращается в плавающую мини-шапку (логотип + стрелка + бургер);
  - первый блок: галерея 2×2, заголовок, бюджет/срок, дизайнер, «Задача» / «Решение»;
  - заглушка блока «План проекта» (габариты из макета);
  - галерея: aside прилипает к низу экрана, пока листается колонка медиа; на мобильном — лента;
  - слайдер «Реализованные проекты»: карточки со срезом угла, листание стрелками и свайпом;
  - подвал.
- **Витрина на GitHub Pages**: https://si-teamru.github.io/kmf/ — статическая сборка страниц
  (без админки и API) при каждом пуше в `main`. (#6)
- **Сверка вёрстки с Figma**: `npm run check:layout` — координаты ключевых элементов на 1440 и 360
  против фреймов Figma (спеки в `tests/layout`).

### Исправлено

- Иконка стрелки ссылки (`link-arrow-98`) была выгружена с обрезанным наконечником; заменена
  полным вектором, добавлен красный вариант. (#7)
- `h2` на мобильном был 30px вместо 16px — в выгрузке не хватало стиля `Mobile/h2`. (#3)

### Известные ограничения

- Раскрытое мобильное меню и вариант для планшета в макете не нарисованы: бургеры без панели,
  на 768–1279 — мобильная раскладка (крупнее).
- Страниц `/projects`, `/privacy`, `/consent`, `/cookies` и формы «Отправить проект» пока нет —
  ссылки на них ведут на 404 / несуществующий якорь.
- Защита ветки `main` недоступна на бесплатном тарифе GitHub — правило «только PR с зелёным CI».
